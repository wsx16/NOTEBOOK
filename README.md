# 🤖 大模型微调量化学习笔记

## 🎯 学习重点

### 大模型微调量化
- **微调技术**：LoRA、QLoRA、P-Tuning参数高效微调
- **量化方法**：GPTQ、AWQ、GGUF 4-bit/8-bit量化
- **模型压缩**：剪枝、蒸馏、知识迁移
- **推理优化**：Flash Attention、Paged Attention内存优化

### 智能体开发
- **Agent架构**：ReAct、Tool Calling、Multi-Agent系统
- **工具集成**：API调用、代码执行、外部工具使用
- **记忆机制**：短期记忆、长期记忆、上下文管理
- **自主学习**：强化学习、元学习、自适应调整

### MCP (Model Context Protocol)
- **协议设计**：客户端-服务器架构、消息格式规范
- **工具封装**：文件系统、数据库、网络服务工具化
- **安全机制**：权限控制、资源隔离、访问审计
- **扩展开发**：自定义工具、服务发现机制

### RAG (检索增强生成)
- **检索技术**：向量数据库、语义搜索、混合检索
- **知识库构建**：文档分块、向量化、索引优化
- **增强策略**：查询重写、多文档融合、相关性排序
- **评估优化**：检索质量、生成质量、端到端性能



## 🛠️ 技术栈

- **框架**：PyTorch、Hugging Face Transformers
- **工具**：vLLM、Ollama、LangChain、LlamaIndex
- **平台**：OpenAI API、Claude API、本地模型部署
- **数据库**：Chroma、Pinecone、Weaviate向量数据库
